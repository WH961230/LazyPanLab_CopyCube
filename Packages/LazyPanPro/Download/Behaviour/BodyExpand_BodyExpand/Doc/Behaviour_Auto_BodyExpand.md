# Behaviour_Auto_BodyExpand BodyExpand

一句话：体型扩散配置占位 参数全在自己 Data 里 这里只做图节点与 Setting 的挂钩

## Setting 字段

| 字段 | 含义 |
|---|---|
| SourceSign | 实体 SourceSign | 实体 Sign，与 ObjConfig.Sign 一致 |

## 使用步骤

1. 在可视化编辑器 Behaviour 标签页找到 Behaviour_Auto_BodyExpand，确认配置数据已生成。
2. 按上表在 Setting 资源里为你的 ObjConfig.Sign 加一条。
3. 需要演示视频时，在本 Doc 目录放 Behaviour_Auto_BodyExpand.mp4，或写 Behaviour_Auto_BodyExpand.url.txt 放一行在线链接。

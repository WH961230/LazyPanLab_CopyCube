# Behaviour_Event_OrbitKeeper OrbitKeeper

一句话：环绕养球菜谱 — 只管养哪些球，加新球只加行，不认识谁在养。 一条=一个持有者的养球库，结构与 WeaponSetting.WeaponItem 复用，只看 Kind=环绕的行。

## Setting 字段

无独立 Setting（逻辑写死在行为脚本内，或复用通用配置）。

## 使用步骤

1. 在可视化编辑器 Behaviour 标签页找到 Behaviour_Event_OrbitKeeper，确认配置数据已生成。
2. 按上表在 Setting 资源里为你的 ObjConfig.Sign 加一条。
3. 需要演示视频时，在本 Doc 目录放 Behaviour_Event_OrbitKeeper.mp4，或写 Behaviour_Event_OrbitKeeper.url.txt 放一行在线链接。

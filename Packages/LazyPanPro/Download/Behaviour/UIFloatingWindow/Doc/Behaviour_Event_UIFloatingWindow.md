# Behaviour_Event_UIFloatingWindow UIFloatingWindow

一句话：浮窗节点只读便签：图节点上直接显示，给用户看的参数说明

## Setting 字段

无独立 Setting（逻辑写死在行为脚本内，或复用通用配置）。

## 使用步骤

1. 在可视化编辑器 Behaviour 标签页找到 Behaviour_Event_UIFloatingWindow，确认配置数据已生成。
2. 按上表在 Setting 资源里为你的 ObjConfig.Sign 加一条。
3. 需要演示视频时，在本 Doc 目录放 Behaviour_Event_UIFloatingWindow.mp4，或写 Behaviour_Event_UIFloatingWindow.url.txt 放一行在线链接。
